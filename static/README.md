# `static/`: the HUD (browser frontend)

Served by the voice app at `/`, through Caddy at `https://artemis-v01`. Plain ES modules with **no build step and no CDN**: everything (fonts included) is local.

| Path | Contents |
|---|---|
| `index.html` | The HUD layout: status strip, conversation panel (with **+ New**), the core (orb button), activity panel, composer, and the mute and hands-free buttons |
| `app.js` | Entry point; it just imports `js/main.js` |
| `js/` | Frontend modules: see [`js/README.md`](js/README.md) |
| `css/artemis.css` | The "Moonlight" theme: color tokens (`--ready` green, `--dusk` violet, `--amber` approvals, `--fault` errors), core state classes (`.core.is-<state>`), phone layout, `prefers-reduced-motion` |
| `fonts/` | Sora (UI) and JetBrains Mono (labels, metrics) as variable woff2, with their OFL licenses |
| `icons/` | App icons (PWA, Apple touch, maskable). Generated by `scripts/make_icons.py` |
| `manifest.json` | PWA manifest: installable to a phone's home screen |
| `favicon.ico` | Browser tab icon |

## Notes

- **The microphone needs HTTPS** (or localhost). Caddy provides the certificate.
- **Type checking:** every file starts with `// @ts-check` and uses JSDoc types. `tsc -p jsconfig.json` runs in strict mode (`./check.sh`). The worklet (`js/pcm-worklet.js`) is the only exception, because the AudioWorklet scope isn't in TypeScript's DOM types.
- **Tests:** `tests/frontend.test.js` runs these modules in Node against a small mock DOM (`npm test`).
- **Per-device settings** live in `localStorage`: access token, session id, mute, hands-free.
